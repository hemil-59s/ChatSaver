# 💾 ChatSaver — Export AI Chats Instantly

> Save your AI conversations as TXT or ZIP
> with one click. Works on almost every AI platform.

---

## ⚡ Install in 30 Seconds

1. **Download ZIP** → Click green `Code` button → `Download ZIP`
2. **Extract** the folder anywhere
3. Open Chrome → type in address bar:
```
   chrome://extensions
```
4. Enable **Developer Mode** (top right toggle)
5. Click **"Load Unpacked"**
6. Select the extracted `ChatSaver` folder
7. ✅ Done — ChatSaver icon appears in toolbar!

---

## 🚀 How to Use

1. Open any AI platform
2. Open any conversation
3. Click **ChatSaver** icon in Chrome toolbar
4. Choose export format:
   - 📄 **TXT** — Plain text file
   - 🗜️ **ZIP** — Compressed archive
5. File downloads automatically!
